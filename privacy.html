Gizlilik Politikası

Son güncelleme: 6 Kasım 2026

"CeTan Kanal Aracı", YouTube kanalı CeTan (@cetan5) sahibinin yalnızca kendi kanalını yönetmek için kullandığı kişisel bir araçtır. Başka kullanıcılara sunulmaz.

Hangi verilere erişilir

Kanal sahibi Google ile giriş yaptığında araç, YouTube Data API ve YouTube Analytics API üzerinden yalnızca kanal sahibinin kendi kanalına ait verilere erişir: videolar, başlıklar, açıklamalar, yorumlar, izlenme ve gelir istatistikleri.

Veriler nasıl kullanılır

Veriler yalnızca kanal sahibinin kendi kanalını yönetmesi (istatistikleri görmek, video bilgilerini düzenlemek, video yüklemek) için kullanılır. Erişim anahtarları yalnızca kanal sahibinin bilgisayarında saklanır.

Paylaşım

Veriler satılmaz, üçüncü kişilerle paylaşılmaz ve reklam amacıyla kullanılmaz.

Erişimi kaldırma

Erişim istenildiği an Google Hesabı → Üçüncü taraf erişimi sayfasından kaldırılabilir.

Uygulamanın Google API'lerinden aldığı bilgileri kullanımı, sınırlı kullanım şartları dahil Google API Hizmetleri Kullanıcı Verileri Politikası'na uyar.

Privacy Policy (English)

"CeTan Kanal Aracı" is a personal tool used only by the owner of the YouTube channel CeTan (@cetan5) to manage their own channel. It is not offered to other users. When the owner signs in with Google, the tool accesses only the owner's own channel data through the YouTube Data API and YouTube Analytics API (videos, titles, descriptions, comments, view and revenue statistics). The data is used only to manage that channel. Access tokens are stored only on the owner's computer. Data is never sold, shared with third parties or used for advertising. Access can be revoked at any time at myaccount.google.com/permissions. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
